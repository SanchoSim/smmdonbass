Чтобы увидеть, что за коммит появился, 
ты можешь использовать команду git fetch для обновления информации 
о удалённом репозитории, а затем git log origin/main..HEAD

git log -p HEAD..origin/main

Она означает:
Покажи коммиты, которые есть в origin/main,
но которых нет в моей текущей ветке


git branch
git branch -a показать текущую ветку

git checkout -b main origin/main
Что это делает:
создаёт локальную ветку main
связывает её с origin/main
переключает тебя на неё

git checkout main
переключится на локальную ветку main
